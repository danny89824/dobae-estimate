# 도배청년단 · 1분 예상 견적 (베타)

서울·경기 프리미엄 도배 **가견적 웹앱** 테스트 버전입니다.

- 공간 → 평형 → 벽지 → 시공방식을 선택하면 예상 견적(범위)을 안내하고, 무료 방문실측 예약을 받습니다.
- 가격은 위태준 대표 가격 산정 시트를 기준으로 하며, 정확한 금액은 방문실측 후 확정됩니다. (베타)

## 데모
GitHub Pages로 배포되면 아래 주소에서 누구나 접속해 테스트할 수 있습니다.
`https://<github-아이디>.github.io/<레포명>/`

## 구성
- `index.html` — 앱 전체 (UI + 계산 로직 + 가격 데이터)
- `assets/logo.png` — 로고
- 가격 수정은 `index.html` 상단 `PRICE` 객체만 변경

## 메모
- 리드(신청) 데이터는 현재 접속자 브라우저의 localStorage에만 저장됩니다. (백엔드 연동 예정)
- 면적은 전용면적 기준 표기.
